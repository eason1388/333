# 333

## 紫微斗數全書・十四主星電子書

手機與桌面均可閱讀的靜態網頁電子書，分為古籍全文、十四主星分類索引與命盤核對。

- 「古籍全文」依維基文庫《紫微斗數全書》卷一至卷三的原有篇章順序連續排版，不按主星拆句，也不附白話；卷二文字圖表保留原樣，篇章目錄可跳轉。
- 收錄 Word 分類索引中的 1,335 筆原句，按十四主星、專論與散見分組。
- 可搜尋原文、翻譯與判讀，並調整閱讀字級；瀏覽器會在本機記住閱讀位置。
- 「命盤核對」可輸入國曆／農曆出生日期、時間與性別取得參考盤，逐筆檢查 1,335 筆索引中可辨識的本命宮位、同宮及地支條件。
- 可貼入文墨天機的「AI 描述／文字命盤」或選取 `.txt`，以其十二宮資料為準；若同時排了參考盤，會顯示十二宮主星比對結果。出生資料與貼上的命盤只在瀏覽器中處理，不會送往伺服器或儲存。
- 開啟 `index.html` 所在的靜態網站即可使用；網頁檔案皆在倉庫根目錄，適合設為 GitHub Pages 的 `main` 分支根目錄。
- iPhone 可在 Safari 使用「分享 → 加入主畫面」。

「原文閱讀」的分類索引資料範圍是 `紫微斗數全書_十四主星_古書原句分類索引_v3.docx` 已分類的 1,335 筆；「古籍全文」另依維基文庫卷一至卷三底本收錄，其他版本字句可能不同。古籍中的疾病、壽命、性別及階級判語僅供文獻理解，不作現代事實預告。

命盤核對採保守的結構規則，列出的是古書原句中「部分條件對上」的段落，不代表全句附加條件成立，也不推算大限、流年或具體事件。出生資料試排使用 [iztro](https://github.com/SylarLong/iztro) 2.6.1（MIT 授權，授權文字見 `vendor/iztro-LICENSE.txt`）；文墨天機可自訂真太陽時、閏月等排盤設定，因此請以匯入的文墨文字盤作最終比對依據。
