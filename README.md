## 紫微斗數全書・十四主星電子書

手機與桌面均可閱讀的靜態網頁電子書，將十四主星分類索引的古書原文、白話翻譯與判讀條件對照呈現。

- 收錄 Word 分類索引中的 1,335 筆原句，按十四主星、專論與散見分組。
- 可搜尋原文、翻譯與判讀，並調整閱讀字級；瀏覽器會在本機記住閱讀位置。
- 開啟 `index.html` 所在的靜態網站即可使用；網頁檔案皆在倉庫根目錄，適合設為 GitHub Pages 的 `main` 分支根目錄。
- iPhone 可在 Safari 使用「分享 → 加入主畫面」。

資料範圍是 `紫微斗數全書_十四主星_古書原句分類索引_v3.docx` 已分類的 1,335 筆，不等於《紫微斗數全書》各版本的完整全文。古籍中的疾病、壽命、性別及階級判語僅供文獻理解，不作現代事實預告。
